01 / GET STARTED

接入前，先对齐这些

项目级约定
01

登录态与请求头

从项目登录态取得访问令牌，以 Authorization: Bearer <token> 传入。HTTP 401 时按项目约定回到登录页。

02

分页与空状态

page 从 1 开始，pageSize 默认 20。列表读取 items，总数读取 total；items=[] 时展示空状态。

03

金额、时间与错误

金额单位为分；UTC 时间按用户时区显示。非 2xx 响应读取 code、message，反馈问题时附 requestId。

02 / USER FLOWS

按页面动作串起接口

订单管理页的查询与操作链路

  1. 查询订单列表 ↗

    用 page、pageSize、status 驱动列表。

  2. 获取订单详情 ↗

    点击行后使用 id 读取最新详情。

  3. 取消未支付订单 ↗

    操作成功后重新查询列表与详情。

填写商品 → 提交订单

创建表单的提交与结果处理

  1. 创建订单 ↗

    禁用提交按钮，防止重复点击；422 时保留表单内容。

  2. 获取订单详情 ↗

    使用创建响应中的 id 跳转详情。

什么时候调用

需鉴权

联调提示

// 调用示例：替换占位值，并按项目约定接入鉴权与错误处理。
const baseUrl = "https://api.example.com/v1";
const path = "/orders/{orderId}/cancel".replace("{orderId}", encodeURIComponent(String("ord_1024")));
const url = new URL(baseUrl.replace(/\/$/, "") + path, "https://YOUR_API_HOST");
// 以下采用第一组鉴权方案，凭据由项目登录态提供。
const body = {
  "reason": "暂时不需要"
};
const response = await fetch(url, {
  method: "POST",
  headers: {
    "Authorization": "Bearer <credentials>",
    "Content-Type": "application/json"
  },
  body: JSON.stringify(body),
});
if (!response.ok) {
  // 在这里结合下方异常响应处理业务提示。
  throw new Error(`HTTP ${response.status}`);
}
const contentType = response.headers.get("content-type") ?? "";
const result = response.status === 204 || response.status === 205
  ? undefined
  : contentType.includes("json")
    ? await response.json()
    : contentType.startsWith("text/")
      ? await response.text()
      : await response.blob();
